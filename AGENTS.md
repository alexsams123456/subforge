# SubForge — инструкции для AI-агента

Перед изменениями кода **прочитай** [docs/AGENT_CONTEXT.md](docs/AGENT_CONTEXT.md) — там архитектура, пайплайн, модули и решения продукта.

## Обязательное правило

Любое изменение поведения, UI, пайплайна, движков, ffmpeg, зависимостей или скриптов **должно сопровождаться обновлением**:

1. [docs/AGENT_CONTEXT.md](docs/AGENT_CONTEXT.md) — технический контекст для агента
2. [README.md](README.md) — если меняется то, что видит пользователь (установка, запуск, возможности)

Не оставляй документацию устаревшей после правок кода.

## Быстрые факты

- Продукт: **SubForge**, локальные субтитры из речи, soft subs в MP4
- Default: движок **Мощный** (`large-v3`), язык **English**
- Пайплайн: ffmpeg → Whisper → temp SRT → ffmpeg mux → delete temp
- UI: CustomTkinter, `app/ui/main_window.py`
